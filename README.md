# prakai-pos

ระบบขายหน้าร้านสำหรับร้านอาหาร คิดต้นทุนต่อจาน และออกเอกสารภาษีตามกฎหมายไทย (VAT 7%, ใบกำกับภาษีอย่างย่อ/เต็มรูป)
ตั้งชื่อตามคุณประกายดาว ผลสอน

| โฟลเดอร์ | หน้าที่ |
| --- | --- |
| `packages/core` | คำนวณบิล VAT service charge ปัดเศษ ต้นทุนสูตร ต้นทุนเฉลี่ย เลขผู้เสียภาษี (pure TS + tests) |
| `apps/api` | Fastify + PostgreSQL (RLS แยกข้อมูลแต่ละร้าน, เอกสารภาษีแก้/ลบไม่ได้, audit log แบบ hash chain) |
| `apps/web` | Next.js หน้าขาย ผังโต๊ะ ชำระเงิน ใบเสร็จ หลังบ้าน |

## หลังบ้าน (ระยะ 2 ต้นทุน)

| หน้า | ทำอะไร |
| --- | --- |
| `/owner/profit` | กำไรขาดทุนรายเดือน, กำไรต่อเมนู + menu engineering, ต้นทุนตามสูตร vs นับจริง |
| `/owner/menu` | ต้นทุนต่อจานจากสูตร, แก้สูตร/ราคา แล้วเห็น food cost ทันที |
| `/owner/stock` | วัตถุดิบ, สูตรย่อย (น้ำจิ้ม น้ำซุป ทำเองในร้าน), รับของ (ภาษีซื้อ), ของเสีย, นับสต็อก |
| `/owner/expenses` | ค่าใช้จ่าย พร้อมภาษีซื้อและหัก ณ ที่จ่าย |

## หน้าร้าน: กะ ใบสั่งครัว และการแก้เอกสาร

| หน้า | ทำอะไร |
| --- | --- |
| `/pos/order/[id]` | ย้ายโต๊ะ รวมบิลโต๊ะอื่นเข้ามา แยกบิล (เลือกรายการและจำนวน) บิลแยกชำระแยกได้ |
| `/pos/order/[id]/pay` | ใส่เลขพร้อมเพย์ในตั้งค่าร้านแล้ว จะสร้าง QR พร้อมเพย์ตามยอดบิล (Thai QR / EMVCo) |
| `/pos/shift` | เปิดกะด้วยเงินทอน นำเงินเข้า–ออก ปิดกะนับเงินจริง เทียบยอดระบบ (X/Z ของกะ) — ต้องเปิดกะก่อนจึงรับเงินได้ |
| `/kitchen/[orderId]` | ใบสั่งครัว 72 มม. แยกสถานี (ครัว/บาร์น้ำ) ต่อรอบที่กดส่งครัว หรือพิมพ์ซ้ำทั้งโต๊ะ |
| `/receipt/[id]` | ผู้จัดการยกเลิกเอกสารของวันนี้ หรือออก**ใบลดหนี้**ทั้งบิลหรือบางรายการสำหรับใบกำกับภาษีของวันก่อน (ออกได้หลายใบจนครบจำนวน คืนเงินสดจะบันทึกเป็นเงินออกของกะ) |
| `/owner/reports` | รายงานภาษีขาย (หักใบลดหนี้) รายงานภาษีซื้อ + สรุปยอดกรอก ภ.พ.30 รายงานสินค้าและวัตถุดิบ (ม.87(3) ยกมา–รับ–จ่าย–คงเหลือ และบัญชีคุมรายตัว) กะของวัน (เงินขาด/เกิน) และค้นเอกสารด้วยเลขที่ |
| `/owner/pp06` | เอกสารประกอบคำขอ ภ.พ.06: ข้อมูลผู้ประกอบการ เครื่องขายและ serial แผนผังการเชื่อมต่อ ช่องวาดตำแหน่งเครื่อง คุณสมบัติตามประกาศฯ ฉบับที่ 46 ตัวอย่างเอกสารและรายงานประจำวัน (เปิดจากตั้งค่าร้าน) |

## เครื่องพิมพ์ในร้าน และความปลอดภัย

| ส่วน | ทำอะไร |
| --- | --- |
| `/owner/settings` → เครื่องพิมพ์ | เพิ่มเครื่องพิมพ์ความร้อน LAN (ESC/POS พอร์ต 9100) แยกใบเสร็จ/ครัว/บาร์ ทดสอบพิมพ์ และสร้างรหัสให้โปรแกรมพิมพ์ในร้าน |
| `/print-agent.mjs` | โปรแกรมพิมพ์ (Node 18+ ไม่ต้องติดตั้งแพ็กเกจ) รันบนคอมในร้าน ดึงงานจากระบบทาง HTTPS แล้วส่งภาพ raster ไปเครื่องพิมพ์ ภาษาไทยไม่เพี้ยนเพราะเบราว์เซอร์วาดเป็นภาพเอง |
| `/receipt/[id]` | หลังรับเงินพิมพ์ใบเสร็จอัตโนมัติ (จ่ายเงินสดเปิดลิ้นชัก) พิมพ์ซ้ำจะมีคำว่า “สำเนา” |
| `/kitchen/[orderId]` | ส่งใบสั่งแต่ละสถานีไปเครื่องพิมพ์ของครัว/บาร์ ถ้าไม่มีเครื่องพิมพ์ใช้การพิมพ์ของเบราว์เซอร์ |
| `/owner/settings` → ยืนยันตัวตนสองขั้น | แอป authenticator (TOTP) + รหัสกู้คืน 8 รหัส · ใส่รหัสผ่านผิด 10 ครั้งล็อก 15 นาที |

## Deploy

ดู [`deploy/README.md`](deploy/README.md) — Dockerfile ของ API และเว็บ, compose สำหรับ VPS (ตามกฎในไฟล์ handoff) และ GitHub Actions ที่ test → build → deploy เมื่อ push `main`

ขายแล้วระบบตัดสต็อกตามสูตรและบันทึกต้นทุนลงบิลตอนชำระเงิน สมุดสต็อก (`stock_movements`) แก้/ลบไม่ได้

## เริ่มพัฒนา

```bash
docker compose -f docker-compose.dev.yml up -d   # PostgreSQL ที่ 127.0.0.1:5433
cp apps/api/.env.example apps/api/.env           # แล้วเปลี่ยน JWT_SECRET
npm install
npm run migrate -w @prakai/api
npm run dev -w @prakai/api                       # API :4000
npm run dev -w @prakai/web                       # เว็บ :3000 (proxy /api → :4000)
```

## ทดสอบ

```bash
npm test          # core unit tests + API integration tests (ต้องเปิด Postgres ก่อน)
npm run typecheck
```
